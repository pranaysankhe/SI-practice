# LearnNest — Class 7 Learning Studio

A colourful, responsive learning companion for a DAV Class 7 student, built with HTML, CSS and JavaScript.

## Run locally

With Python installed, run from the repository directory:

```sh
python -m http.server 8000
```

Open http://localhost:8000 in your browser. No installation or build step is required.

## Included

- 74 original concept chapters across 11 learning areas
- 222 explanations with everyday examples and 222 multiple-choice questions
- Chapter tests with explained answers, flashcards and notebook activities
- A 12-question revision check unlocked after learning four chapters in a subject
- Progress and test results saved in the current browser's local storage

## Files

- `index.html`: application entry point
- `style.css`: responsive interface and colourful theme
- `app.js`: navigation, lessons, quizzes and local progress
- `content.js`: subject and chapter content

## Curriculum scope

This is a foundation library, not a verified match to a particular school's complete 2026–27 DAV syllabus. Literature and Moral Education modules teach transferable skills rather than replacing prescribed texts. Exact textbook contents are needed for full chapter mapping. Tests are short revision checks rather than complete school exams. Written activities are not automatically graded.

Progress does not sync across devices and can be lost when browser data is cleared. Google Fonts is optional; system fonts are used as a fallback.

Live app: https://learnnest-class7.pranay-sankhe-cgi.chatgpt.site (access is controlled separately from this repository).
